# غَرْسة · Gharsah

**نغرس حُبّ القرآن… ويكبر معهم**

غَرْسة تطبيق يعلّم الأطفال (٨–١٣ سنة) حفظ القرآن والحديث والقيم الإسلامية عبر **حصة صوتية تفاعلية بإحساس مباشر** يقودها معلّم ذكاء اصطناعي، ثم يحوّل كل درس إلى **مشروع عملي** يطبّقه الطفل في حياته ويحكيه صوتيًا. ووليّ الأمر يشترك ويتابع التقدّم من لوحة متابعة.

Gharsah is a Flutter app that helps children aged 8–13 memorize Quran, hadith and Islamic values through a live-feel voice lesson led by an AI teacher, turns each lesson into a real-life project the child reports back on by voice, and gives parents a progress dashboard.

## الضوابط غير القابلة للتفاوض · Non-negotiables

1. **لا يولّد الذكاء الاصطناعي نص قرآن أو حديث أبدًا.** القرآن من ملف محقّق داخل التطبيق، والحديث من مصدر موثّق مع التخريج.
2. **خصوصية الطفل:** لا يُطلب من الطفل أي بيانات شخصية؛ يدخل برمز ربط فقط.
3. **الدفع عبر Google Play فقط.**
4. **السيرفر مصدر الحقيقة** للربط والتسليمات والتقدّم.

التفاصيل في [`CLAUDE.md`](CLAUDE.md) و[`ai/GUARDRAILS.md`](ai/GUARDRAILS.md).
